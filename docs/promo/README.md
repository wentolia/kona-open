## Re-rendering

1. `python3 src/gen.py lib` builds the test library (needs ffmpeg and Pillow).
2. Start `npm run dev` in `web/`.
3. Capture each scene, for example `node src/shot.cjs 1600 840 a.png src/a.json` (`a`, `v2`, `v3`, `v4` at 1600×840; `b`, `c` at 1000×760).
4. `python3 src/compose.py` writes the layout pages. Serve that folder with `python3 -m http.server 8765` and run `node src/render.cjs`. For fonts, put a `fonts` link to `web/node_modules/@fontsource` in it.
