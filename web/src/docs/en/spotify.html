Listening on Spotify

Kona has no server. Your browser talks to Spotify directly to play music. To allow this, you create an app in Spotify for Developers and enter its Client ID in Kona. This is done once and costs nothing.

Requirements: a Spotify Premium account (required by the Web Playback SDK and, since February 2026, by Spotify's rules for developer apps), and a desktop browser with DRM (Widevine) support such as Chrome, Edge or Firefox. Phone browsers cannot play Spotify.

Labels below are those of the English interface. Where a control is shown only in Japanese, the Japanese label follows in parentheses.

How it works

Client IDFrom your own Spotify for Developers account. Kona contains no one's ID.
Sign-inPKCE, which uses no client secret. The secret is never entered anywhere.
ScopesPlayback (streaming), profile (user-read-email user-read-private, required by the SDK), saved albums (user-library-read), playback state and control (user-read-playback-state user-modify-playback-state). No scope that changes playlists or your library is requested.
TokenKept only in this browser (localStorage). Signing out removes it.
NetworkSpotify only: accounts.spotify.com, api.spotify.com, the player at sdk.scdn.co and covers at i.scdn.co. Nothing is sent to anyone else, including the developer.
Stored on the deviceThe token, play counts and listening history (track titles and the like, as for any album). Track lists and covers are not stored; they are read from Spotify each time.
Third-party scriptsSpotify's Web Playback SDK, loaded only after you choose to use Spotify.

What works and what does not

  • Albums saved in Spotify appear on a shelf named Spotify.
  • Shelves, cats and listening history work from track information (title, artist, length) as usual.
  • Covers are not altered. Spines and record labels use only the average colour.
  • The track panel shows Open in Spotify (Spotify で開く).
  • Spotify audio is protected by DRM and cannot pass through Kona's audio processing. Equalizer, waveform, spectrum, level, volume normalisation, crossfade, layered sounds and reverb do not apply. The sleep timer lowers the volume gradually and then stops.
  • Under Spotify's rules, a developer app in Development Mode can be used by at most five people.

1. Create the app

  1. Open the Spotify for Developers dashboard and log in with your Spotify account.
  2. Press Create app and fill in:
    • App name and App description: anything (for example Kona).
    • Redirect URIs: the URL where you open Kona, exactly (for example https://wentolia.github.io/kona-open/), including the trailing /. Copying the string shown in Settings → Other → Sources avoids mistakes.
    • Which API/SDKs are you planning to use?: Web API and Web Playback SDK.
    • Read and accept the Developer Terms of Service and Design Guidelines, then save.
  3. The Client ID (32 alphanumeric characters) is under Settings → Basic Information. The client secret is not used.
  4. If others will use it, add their name and Spotify email address under User Management.

2. Enter it in Kona

  1. Open Settings → Other → Sources (Google Drive, Spotify).
  2. Paste the Client ID and press Save and sign in.
  3. Allow access on Spotify's screen.
  4. Your saved albums appear on the shelf.

Spotify is then offered on the start screen and in the Folders menu. If Spotify was open last time, Kona opens it again.

Troubleshooting

Message (shown in Japanese)Check
Spotify にサインインできませんでした (sign-in failed)The Client ID is correct, and the Redirect URI matches the one shown in Kona character for character.
Premium のアカウントが要ります (Premium required)The account is Premium.
このブラウザでは Spotify の曲を鳴らせません (this browser cannot play)You are using Chrome, Edge or Firefox on a computer, and playback of protected content (DRM) is not disabled.
再生を始められませんでした (playback could not start)Spotify is not being controlled from another device. Wait a moment and try again.

Stopping

  • Sign out under Settings → Other → Sources removes the token from this browser. Remove Client ID deletes the setting as well.
  • To revoke access itself, remove Kona under Apps in your Spotify account.
  • Deleting the app in the dashboard also invalidates the Client ID.
