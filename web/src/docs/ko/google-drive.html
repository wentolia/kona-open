Google Drive에서 듣기

Kona에는 서버가 없습니다. Google Drive의 음악은 이용자의 브라우저가 Google에서 직접 읽어 옵니다. 이를 위해 이용자 자신의 Google Cloud에서 OAuth 클라이언트 ID를 만들어 Kona에 입력합니다. 한 번만 만들면 되며 비용은 들지 않습니다.

Kona의 화면은 일본어와 영어로 제공됩니다. 아래에서는 영어 화면의 표기를 쓰고, 일본어로만 표시되는 항목은 괄호 안에 일본어 표기를 덧붙입니다.

구조

클라이언트 ID이용자의 Google Cloud에서 만든 것. Kona에는 누구의 ID도 들어 있지 않습니다.
권한읽기 전용(drive.readonly). Kona는 Drive에 쓸 수 없습니다.
토큰이 탭 안(sessionStorage)에만 저장되며 약 1시간 후 만료됩니다. 리프레시 토큰은 받지 않습니다.
통신처Google API(www.googleapis.com)뿐입니다. 개발자를 포함해 그 밖의 누구에게도 아무것도 보내지 않습니다.
기기에 남는 것읽어 들인 태그와 커버, 기기에 보관하기로 한 앨범의 곡. 브라우저의 사이트 데이터를 지우면 사라집니다.
외부 스크립트읽지 않습니다. Google 라이브러리도 쓰지 않으며 CSP로 금지합니다.

Google의 파일 선택 화면(Picker)을 쓰면 권한을 선택한 파일로 한정할 수 있지만, Picker는 Google 스크립트를 읽어 와야 하므로 외부 스크립트를 읽지 않는다는 방침과 양립하지 않습니다. 그래서 읽기 전용 권한을 쓰고, 폴더는 Kona 안에서 고릅니다.

1. 프로젝트를 만들고 Drive API를 사용 설정하기

  1. Google Cloud 콘솔을 열고 프로젝트 선택에서 새 프로젝트를 만듭니다. 이름은 자유입니다(예: kona).
  2. API 및 서비스 → 라이브러리에서 Google Drive API를 찾아 사용 설정합니다.

2. 동의 화면 설정하기

  1. API 및 서비스 → OAuth 동의 화면(또는 Google Auth Platform)을 열고 시작하기를 누릅니다.
  2. 앱 이름(예: Kona)과 지원 이메일 주소를 입력합니다.
  3. 대상은 외부를 선택합니다.
  4. 연락처 이메일 주소를 입력하고 만듭니다.
  5. 대상에서 게시 상태가 테스트 중인지 확인하고, 테스트 사용자에 자신의 Google 계정을 추가합니다. 테스트 중인 상태로 쓸 수 있으므로 심사는 필요 없습니다. 로그인할 수 있는 사람은 테스트 사용자로 추가한 사람뿐입니다.
  6. 데이터 액세스에서 범위 .../auth/drive.readonly를 추가합니다. 생략하면 로그인할 때 요청됩니다.

3. 클라이언트 ID 만들기

  1. 클라이언트 → 클라이언트 만들기를 누릅니다.
  2. 유형은 웹 애플리케이션을 선택합니다.
  3. 승인된 자바스크립트 원본에 Kona를 여는 URL의 출처를 입력합니다(예: https://wentolia.github.io).
  4. 승인된 리디렉션 URI에 Kona를 여는 URL을 그대로 입력합니다(예: https://wentolia.github.io/kona-open/). 끝의 /까지 일치시켜야 합니다. Kona의 Drive 화면에 표시되는 문자열을 복사하면 확실합니다.
  5. 만들면 클라이언트 ID(…apps.googleusercontent.com)가 표시됩니다. 클라이언트 보안 비밀은 쓰지 않습니다.

4. Kona에 입력하기

  1. 설정의 Other → Sources (Google Drive, Spotify)에서 Enter client ID를 누릅니다. 입력한 뒤에는 시작 화면과 Folders 메뉴에서도 열 수 있습니다.
  2. 클라이언트 ID를 붙여 넣고 Save and sign in(保存してサインイン)을 누릅니다.
  3. Google 화면에서 계정을 고릅니다. "Google에서 확인하지 않은 앱"이라고 표시되면 계속을 누릅니다. 직접 만든 앱이 심사를 받지 않았다는 뜻입니다.
  4. 음악이 들어 있는 폴더로 이동해 그 폴더를 엽니다.

다음부터는 시작 화면에 그 폴더가 표시됩니다. 토큰은 약 1시간 후 만료되므로, 만료되면 알림에서 다시 로그인하십시오.

스마트폰에서 쓸 때

  • 곡은 재생할 때 Drive에서 가져옵니다. 모바일 데이터에서는 데이터 사용량이 발생합니다(FLAC은 곡당 약 20~40MB).
  • 자주 듣는 앨범은 곡 목록의 Keep on device(端末に残す)로 브라우저 안에 저장하면 이후에는 통신하지 않습니다.
  • 태그와 커버는 한 번 읽으면 기기에 남으므로 두 번째부터는 빨리 읽힙니다.
  • iPhone의 Safari는 한동안 쓰지 않은 사이트의 데이터를 지울 수 있습니다. 홈 화면에 추가하면 남아 있기 쉽습니다.

사용을 중단할 때

  • Kona의 Sign out으로 이 탭의 토큰을 지울 수 있습니다.
  • 권한 자체는 Google 계정의 서드 파티 연결에서 취소할 수 있습니다.
  • Google Cloud 프로젝트를 삭제하면 클라이언트 ID도 무효가 됩니다.

면책

Kona는 MIT 라이선스로 제공되며 보증하지 않습니다. 클라이언트 ID와 계정의 관리는 이용자의 책임입니다.
