Spotify로 듣기

Kona에는 서버가 없습니다. Spotify의 음악은 이용자의 브라우저가 Spotify와 직접 통신하여 재생합니다. 이를 위해 이용자가 Spotify for Developers에서 앱을 직접 만들고 그 Client ID를 Kona에 입력합니다. 한 번만 만들면 되며 비용은 들지 않습니다.

필요한 것: Spotify Premium 계정. Web Playback SDK의 규정과 2026년 2월 이후 개발자용 앱의 규정에 따른 것입니다. Widevine DRM을 지원하는 Chrome, Edge, Firefox 등의 컴퓨터 브라우저. 스마트폰 브라우저에서는 재생할 수 없습니다.

구조

Client ID이용자의 Spotify for Developers에서 만든 것. Kona에는 누구의 ID도 들어 있지 않습니다.
로그인클라이언트 보안 비밀을 쓰지 않는 PKCE 방식. 보안 비밀은 어디에도 입력하지 않습니다.
권한재생용 streaming, SDK가 요구하는 프로필용 user-read-email과 user-read-private, 저장한 앨범을 읽는 user-library-read, 재생 기기를 확인하고 조작하는 user-read-playback-state와 user-modify-playback-state. 재생 목록이나 라이브러리를 변경하는 권한은 요청하지 않습니다.
토큰이 브라우저의 localStorage에만 저장합니다. 로그아웃하면 삭제됩니다.
통신처Spotify의 accounts.spotify.com, api.spotify.com, 재생 부품 sdk.scdn.co, 커버 i.scdn.co뿐입니다. 개발자를 포함해 그 밖의 누구에게도 아무것도 보내지 않습니다.
기기에 남는 것토큰과, 다른 곡과 마찬가지로 곡 제목 등이 담긴 재생 횟수·재생 기록. 곡 목록과 커버는 저장하지 않고, 열 때마다 Spotify에서 읽어 옵니다.
외부 스크립트Spotify를 쓰기로 한 경우에만 Spotify의 Web Playback SDK를 읽어 옵니다.

되는 것과 안 되는 것

  • Spotify에 저장한 앨범이 Spotify라는 이름의 선반에 놓입니다.
  • 선반, 고양이, 재생 기록은 곡의 제목·아티스트·길이를 바탕으로 평소대로 작동합니다.
  • 커버는 가공하지 않습니다. 책등 무늬와 레코드 라벨에는 쓰지 않고 평균색만 씁니다.
  • 곡 목록 패널에 'Spotify에서 열기'를 표시합니다.
  • Spotify의 음성은 DRM으로 보호되어 Kona의 음성 처리를 거칠 수 없습니다. 이퀄라이저, 파형, 스펙트럼, 레벨, 음량 정규화, 크로스페이드, 환경음, 잔향은 적용되지 않습니다. 취침 타이머는 음량을 서서히 낮춘 뒤 멈춥니다.
  • Spotify의 규정에 따라 Development Mode의 개발자용 앱은 최대 5명까지 쓸 수 있습니다.

1. 앱 만들기

  1. Spotify for Developers 대시보드를 열고 Spotify 계정으로 로그인합니다.
  2. Create app을 누르고 다음과 같이 입력합니다.
    • App name, App description: 자유입니다. 예를 들어 Kona로 합니다.
    • Redirect URIs: Kona를 여는 URL을 그대로 입력합니다. 공개판이라면 https://wentolia.github.io/kona-open/입니다. 끝의 /까지 일치시켜야 합니다. 설정의 '기타' → 'Google Drive와 Spotify'에 표시되는 문자열을 복사하면 확실합니다.
    • Which API/SDKs are you planning to use?: Web API와 Web Playback SDK를 선택합니다.
    • Developer Terms of Service와 Design Guidelines를 읽고 동의한 뒤 저장합니다.
  3. 만든 앱의 Settings → Basic Information에 영숫자 32자의 Client ID가 표시됩니다. Client secret은 쓰지 않습니다.
  4. 다른 사람도 쓴다면 User Management에 그 사람의 이름과 Spotify 이메일 주소를 추가합니다.

2. Kona에 입력하기

  1. 설정의 '기타' → 'Google Drive와 Spotify'를 엽니다.
  2. Client ID를 붙여 넣고 '저장하고 로그인'을 누릅니다.
  3. Spotify 화면에서 허용합니다.
  4. 저장한 앨범이 선반에 놓입니다.

다음부터는 시작 화면과 '폴더' 메뉴에서 열 수 있습니다. 지난번에 Spotify를 열어 두었다면 그대로 엽니다.

잘 안 될 때

표시확인할 것
Spotify에 로그인하지 못했습니다Client ID가 올바른지. Redirect URI가 Kona의 표시와 한 글자도 다르지 않은지.
Spotify 곡을 재생하려면 Premium 계정이 필요합니다계정이 Premium인지.
이 브라우저에서는 Spotify 곡을 재생할 수 없습니다컴퓨터의 Chrome, Edge, Firefox인지. DRM에 의한 보호된 콘텐츠 재생이 꺼져 있지 않은지.
Spotify에서 재생을 시작하지 못했습니다다른 기기에서 Spotify를 조작하고 있지 않은지. 잠시 기다린 뒤 다시 시도하십시오.

사용을 중단할 때

  • 설정의 '기타' → 'Google Drive와 Spotify'에서 '로그아웃'을 누르면 이 브라우저의 토큰이 삭제됩니다. 'Client ID 삭제'를 누르면 설정까지 삭제됩니다.
  • 권한 자체는 Spotify 계정의 앱에서 취소할 수 있습니다.
  • 대시보드에서 앱을 삭제하면 Client ID도 무효가 됩니다.

면책

Kona는 MIT 라이선스로 제공되며 보증하지 않습니다. Kona는 Spotify의 공식 앱이 아니며 Spotify와 관계가 없습니다. Client ID와 계정의 관리, 그리고 Spotify의 개발자 약관과 디자인 가이드라인 준수는 이용자의 책임입니다.
