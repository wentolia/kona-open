개인정보 처리와 이용 조건

Kona는 개인이 개발하여 무료로 공개하는 브라우저 음악 플레이어입니다. 이 문서는 공개판(wentolia.github.io/kona-open)과 그 소스 코드에 적용됩니다.

수집하지 않는 정보

  • Kona에는 서버가 없으며 접속 분석도 하지 않습니다. 개발자는 이용자의 음악, 재생 기록, 설정, 이름, 위치를 받지 않습니다.
  • 설정, 재생 기록, 곡 정보는 이용 중인 브라우저 안(localStorage, IndexedDB, Cache Storage)에만 저장됩니다. 설정의 Other → Data에서 내보내기와 삭제를 할 수 있습니다.

기기 밖으로 전송되는 정보

상황수신처전송되는 정보

리스닝 파티상대방의 기기(호스트와 참가자 사이에서만)서로의 IP 주소, 이름, 고양이, 채팅, 통화 음성, 재생 중인 곡 제목, 선반에 있는 앨범의 제목과 축소한 커버, 선물한 아이템. 호스트가 선택한 경우에 한해 호스트가 있는 도도부현 또는 국가.

위치 정보

  • Local keepsakes(ご当地の品)를 켠 경우에만 하루 한 번 브라우저의 위치 정보를 사용합니다.
  • 좌표는 기기 안에서 도도부현 또는 국가 코드로 변환한 뒤 즉시 폐기합니다. 저장하지도 전송하지도 않습니다.
  • 브라우저나 OS는 위치를 구할 때 Google 또는 Apple의 위치 서비스를 사용할 수 있습니다. 이는 브라우저와 OS의 처리입니다.

통화

  • 마이크는 호스트가 통화를 허용하고 이용자 본인이 마이크를 켠 경우에만 사용합니다.
  • Kona는 통화도 음악도 녹음하지 않습니다.

이용 조건

  • Kona는 MIT 라이선스로 제공되며 보증하지 않습니다. 이용으로 발생한 손해에 대해 개발자는 책임을 지지 않습니다.
  • 재생하는 음악은 이용자가 소유하고 있거나 이용할 권리가 있는 것으로 한정하십시오.
  • 리스닝 파티는 아는 사람끼리 사용하십시오. 초대 링크를 SNS 등 불특정 다수가 볼 수 있는 곳에 게시하지 마십시오. 재생하는 음악의 권리에 유의할 책임은 호스트에게 있습니다.
  • 13세 미만은 보호자와 함께 사용하십시오. 파티에서 호스트는 권한(権限)에서 상대를 내보낼 수 있고, 참가자는 언제든지 나가기(抜ける)로 퇴장할 수 있습니다.
  • Google Drive와 Spotify의 클라이언트 ID 및 계정 관리, 그리고 각 회사의 약관(Google API Services User Data Policy, Spotify Developer Terms) 준수는 이용자의 책임입니다. Kona는 Google 또는 Spotify의 공식 앱이 아닙니다.
  • 사용 중인 소프트웨어의 라이선스는 설정의 Other → About Kona에서 열 수 있는 THIRD_PARTY_NOTICES.txt에 있습니다.

개정

기능이 바뀌면 이 문서를 개정합니다. 개정 이력은 소스 코드 저장소에서 확인할 수 있습니다.
