Spotify で聴く

Kona はサーバーを持ちません。Spotify の曲は、利用者のブラウザが Spotify と直接通信して再生します。そのために、利用者自身が Spotify for Developers でアプリを作成し、その Client ID を Kona に入力します。作成は一度だけで、料金はかかりません。

必要なもの: Spotify Premium のアカウント。Web Playback SDK の規定と、2026 年 2 月以降の開発者向けアプリの規定によります。Widevine の DRM に対応した、Chrome、Edge、Firefox などのパソコンのブラウザ。スマートフォンのブラウザでは再生できません。

仕組み

Client ID利用者の Spotify for Developers のもの。Kona には誰の ID も含まれていません。
サインインクライアントシークレットを使わない PKCE 方式。シークレットはどこにも入力しません。
権限再生の streaming、SDK が要求するプロフィールの user-read-email と user-read-private、保存したアルバムを読む user-library-read、再生先を確認・操作する user-read-playback-state と user-modify-playback-state。プレイリストやライブラリを変更する権限は求めません。
トークンこのブラウザの localStorage にだけ保存します。サインアウトで削除されます。
送信先Spotify の accounts.spotify.com、api.spotify.com、再生部品の sdk.scdn.co、ジャケットの i.scdn.co のみ。開発者を含め、ほかには何も送りません。
端末に残るものトークンと、ほかの曲と同じく曲名などを含む再生回数・再生履歴。曲目とジャケットは保存せず、開くたびに Spotify から読み込みます。
外部スクリプトSpotify を使うと決めた場合に限り、Spotify の Web Playback SDK を読み込みます。

できること・できないこと

  • 棚には、Spotify で保存したアルバムが「Spotify」という名前で並びます。
  • 棚、猫、再生履歴は、曲名・アーティスト・長さに基づいて通常どおり動きます。
  • ジャケットは加工しません。背表紙の模様とレコードのレーベルには使わず、平均色だけを使います。
  • 曲目パネルに「Spotify で開く」を表示します。
  • Spotify の音声は DRM で保護されており、Kona の音声処理を通せません。イコライザー、波形、スペクトラム、レベル、音量の正規化、クロスフェード、環境音、余韻は無効です。おやすみタイマーは音量を徐々に下げて止めます。
  • Development Mode の開発者向けアプリを使えるのは、Spotify の規定により 5 人までです。

1. アプリを作成する

  1. Spotify for Developers のダッシュボードを開き、Spotify のアカウントでログインします。
  2. 「Create app」を押し、次のように入力します。
    • App name、App description: 任意です。例えば Kona とします。
    • Redirect URIs: Kona を開いている URL をそのまま入力します。公開版なら https://wentolia.github.io/kona-open/ です。末尾の / まで一致させてください。設定の「その他」→「Google Drive と Spotify」に表示される文字列をコピーすると確実です。
    • Which API/SDKs are you planning to use?: Web API と Web Playback SDK を選びます。
    • Developer Terms of Service と Design Guidelines を読み、同意して保存します。
  3. 作成したアプリの Settings → Basic Information に 32 文字の英数字の Client ID が表示されます。Client secret は使いません。
  4. ほかの人も使う場合は、User Management にその人の名前と Spotify のメールアドレスを追加します。

2. Kona に入力する

  1. 設定の「その他」→「Google Drive と Spotify」を開きます。
  2. Client ID を貼り付け、「保存してサインイン」を押します。
  3. Spotify の画面で許可します。
  4. 保存したアルバムが棚に並びます。

次回からは、開始画面と「フォルダ」のメニューから開けます。前回 Spotify を開いていた場合は、そのまま開きます。

このブラウザでは鳴らせませんパソコンの Chrome、Edge、Firefox か。DRM による保護されたコンテンツの再生が無効になっていないか。
再生を始められませんでした別の端末で Spotify を操作していないか。少し待ってから再度試してください。

利用をやめる

  • 設定の「その他」→「Google Drive と Spotify」の「サインアウト」で、このブラウザのトークンを削除できます。「Client ID を消す」で設定ごと削除できます。
  • 権限そのものは、Spotify アカウントの「アプリ」から取り消せます。
  • ダッシュボードでアプリを削除すると、Client ID も無効になります。
