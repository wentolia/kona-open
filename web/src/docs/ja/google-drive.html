Google Drive から聴く

Kona はサーバーを持ちません。Google Drive の曲は、利用者のブラウザが Google から直接読み込みます。そのために、利用者自身の Google Cloud で OAuth クライアント ID を作成し、Kona に入力します。作成は一度だけで、料金はかかりません。

仕組み

クライアント ID利用者の Google Cloud のもの。Kona には誰の ID も含まれていません。
権限読み取りのみ（drive.readonly）。Kona は Drive に書き込めません。
トークンこのタブの中（sessionStorage）にだけ保存し、約 1 時間で失効します。リフレッシュトークンは受け取りません。
送信先Google の API（www.googleapis.com）のみ。開発者を含め、ほかには何も送りません。
端末に残るもの読み取ったタグとジャケット、「端末に残す」を選んだアルバムの曲。ブラウザのサイトデータを消すと消えます。
外部スクリプト読み込みません。Google のライブラリも使わず、CSP で禁止しています。

Google のファイル選択画面（Picker）を使えば権限を選んだファイルに限定できますが、Picker は Google のスクリプトの読み込みを必要とし、外部スクリプトを読まない方針と両立しません。そのため読み取り専用の権限を使い、フォルダは Kona の中で選びます。

1. プロジェクトを作成し、Drive API を有効にする

  1. Google Cloud コンソールを開き、プロジェクトの選択から新しいプロジェクトを作成します。名前は任意です（例: kona）。
  2. 「API とサービス」→「ライブラリ」で Google Drive API を検索し、有効にします。

2. 同意画面を設定する

  1. 「API とサービス」→「OAuth 同意画面」（または Google Auth Platform）を開き、「開始」を押します。
  2. アプリ名（例: Kona）とサポート用のメールアドレスを入力します。
  3. 対象は「外部」を選びます。
  4. 連絡先のメールアドレスを入力して作成します。
  5. 「対象」で公開ステータスが「テスト中」であることを確認し、「テストユーザー」に自分の Google アカウントを追加します。テスト中のまま使えるため、審査は不要です。サインインできるのはテストユーザーに追加した人だけです。
  6. 「データアクセス」で .../auth/drive.readonly をスコープに追加します。省略してもサインイン時に求められます。

3. クライアント ID を作成する

  1. 「クライアント」→「クライアントを作成」を押します。
  2. 種類は「ウェブ アプリケーション」を選びます。
  3. 「承認済みの JavaScript 生成元」に、Kona を開いている URL のオリジンを入力します（例: https://wentolia.github.io）。
  4. 「承認済みのリダイレクト URI」に、Kona を開いている URL をそのまま入力します（例: https://wentolia.github.io/kona-open/）。末尾の / まで一致させてください。Kona の Drive の画面に表示される文字列をコピーすると確実です。
  5. 作成すると、クライアント ID（…apps.googleusercontent.com）が表示されます。クライアントシークレットは使いません。

4. Kona に入力する

  1. 設定の「その他」→「読み込み元」で「クライアントIDを入れる」を押します。入力後は、開始画面と「フォルダ」のメニューからも開けます。
  2. クライアント ID を貼り付け、「保存してサインイン」を押します。
  3. Google の画面でアカウントを選びます。「Google はこのアプリを確認していません」と表示された場合は「続行」を押します。自分で作成したアプリが審査を受けていないことを示す表示です。
  4. 曲の入ったフォルダまで進み、そのフォルダを開きます。

次回からは、開始画面にそのフォルダが表示されます。トークンは約 1 時間で失効するため、失効したら通知から再びサインインしてください。

スマートフォンで使う場合

  • 曲は再生時に Drive から取得します。モバイル通信ではデータ通信量を消費します（FLAC は 1 曲あたり 20〜40 MB 程度）。
  • よく聴くアルバムは、曲目の「端末に残す」でブラウザの中に保存すると、以後は通信しません。
  • タグとジャケットは一度読み込めば端末に残るため、2 回目以降の読み込みは速くなります。
  • iPhone の Safari は、しばらく使っていないサイトのデータを削除することがあります。ホーム画面に追加すると残りやすくなります。

利用をやめる

  • Kona の「サインアウト」で、このタブのトークンを削除できます。
  • 権限そのものは、Google アカウントのサードパーティ接続から取り消せます。
  • Google Cloud のプロジェクトを削除すると、クライアント ID も無効になります。
