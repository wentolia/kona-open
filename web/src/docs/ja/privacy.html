プライバシーと利用条件

Kona は個人が開発し、無料で公開しているブラウザの音楽プレイヤーです。この文書は公開版（wentolia.github.io/kona-open）と、そのソースコードに適用されます。

収集しない情報

  • Kona はサーバーを持たず、アクセス解析も行いません。開発者は、利用者の曲、再生履歴、設定、名前、位置を受け取りません。
  • 設定、再生履歴、曲の情報は、利用しているブラウザの中（localStorage、IndexedDB、Cache Storage）にだけ保存します。設定の「その他」→「データ」から書き出しと消去ができます。

端末の外に送られる情報

場面送信先送られる情報
公開版を開くGitHub PagesIP アドレスなど、ウェブサーバーが通常記録する情報。扱いは GitHub の方針に従います。
Google Drive から聴くGoogle の API利用者自身が作成した Client ID によるサインインと、読み取りの要求。権限は読み取りのみです。
Spotify で聴くSpotify利用者自身が作成した Client ID によるサインインと、再生の操作。

リスニングパーティー相手の端末（ホストと参加者の間のみ）互いの IP アドレス、名前、猫、チャット、通話の音声、再生中の曲名、棚のアルバムの題名と縮小したジャケット、贈った品。ホストが選んだ場合に限り、ホストのいる都道府県または国。

位置情報

  • 「ご当地の品」を有効にした場合に限り、1 日 1 回、ブラウザの位置情報を使います。
  • 座標は端末の中で都道府県または国のコードに変換し、直ちに破棄します。保存も送信もしません。
  • ブラウザや OS は、位置を求める際に Google や Apple の位置情報サービスを使うことがあります。これはブラウザと OS の扱いです。

通話

  • マイクは、ホストが通話を許可し、利用者本人がマイクを有効にした場合に限り使います。
  • Kona は通話も曲も録音しません。

利用条件

  • Kona は MIT ライセンスで提供され、無保証です。利用によって生じた損害について、開発者は責任を負いません。
  • 再生する曲は、利用者が所有しているか、利用する権利を持つものに限ってください。
  • リスニングパーティーは知人どうしで使ってください。招待リンクを SNS など不特定多数が見る場所に掲載しないでください。流す曲の権利に配慮する責任はホストにあります。
  • 13 歳未満の方は、保護者と一緒に使ってください。パーティーでは、ホストは「権限」から相手を退出させることができ、参加者はいつでも「抜ける」で退出できます。
  • Google Drive と Spotify の Client ID とアカウントの管理、ならびに各社の規約（Google API Services User Data Policy、Spotify Developer Terms）の遵守は、利用者の責任です。Kona は Google と Spotify の公式アプリではありません。
  • 使用しているソフトウェアのライセンスは、設定の「Kona について」から開ける THIRD_PARTY_NOTICES.txt にあります。

改定

機能の変更に合わせて改定します。改定の履歴はソースコードのリポジトリで確認できます。
