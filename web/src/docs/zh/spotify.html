用 Spotify 收听

Kona 没有服务器。Spotify 的音乐由用户的浏览器直接与 Spotify 通信并播放。为此，用户需在 Spotify for Developers 中自行创建应用，并将其 Client ID 填入 Kona。只需创建一次，不产生费用。

所需条件：Spotify Premium 账号，这是 Web Playback SDK 的规定以及 2026 年 2 月起开发者应用的规定所要求的。支持 Widevine DRM 的 Chrome、Edge、Firefox 等电脑浏览器。手机浏览器无法播放。

工作方式

Client ID来自用户自己的 Spotify for Developers。Kona 中不含任何人的 ID。
登录不使用客户端密钥的 PKCE 方式。任何地方都不需要输入密钥。
权限用于播放的 streaming，SDK 要求的个人资料 user-read-email 和 user-read-private，读取已保存专辑的 user-library-read，确认和操作播放设备的 user-read-playback-state 和 user-modify-playback-state。不请求修改播放列表或资料库的权限。
令牌只保存在此浏览器的 localStorage 中。退出登录后删除。
通信对象仅 Spotify 的 accounts.spotify.com、api.spotify.com、播放组件 sdk.scdn.co 和封面 i.scdn.co。不向包括开发者在内的任何其他人发送任何内容。
设备上保留的内容令牌，以及与其他曲目一样包含曲名等信息的播放次数和播放记录。曲目列表和封面不保存，每次打开时从 Spotify 读取。
外部脚本仅在决定使用 Spotify 时加载 Spotify 的 Web Playback SDK。

可用与不可用的功能

  • 在 Spotify 中保存的专辑会排列在名为 Spotify 的书架上。
  • 书架、猫和播放记录依据曲名、艺人和时长照常运作。
  • 不加工封面。书脊图案和唱片标签不使用封面，只使用其平均色。
  • 曲目面板中显示“在 Spotify 中打开”。
  • Spotify 的音频受 DRM 保护，无法经过 Kona 的音频处理。均衡器、波形、频谱、电平、音量标准化、交叉淡入淡出、环境音和余响均不生效。睡眠定时器会逐渐降低音量后停止。
  • 根据 Spotify 的规定，Development Mode 的开发者应用最多 5 人使用。

1. 创建应用

  1. 打开 Spotify for Developers 控制台，用 Spotify 账号登录。
  2. 点击 Create app，并按如下填写：
    • App name、App description：任意，例如 Kona。
    • Redirect URIs：原样输入打开 Kona 的 URL。公开版为 https://wentolia.github.io/kona-open/。末尾的 / 也须一致。复制设置的“其他”→“Google Drive 和 Spotify”中显示的字符串最为可靠。
    • Which API/SDKs are you planning to use?：选择 Web API 和 Web Playback SDK。
    • 阅读并同意 Developer Terms of Service 和 Design Guidelines，然后保存。
  3. 所建应用的 Settings → Basic Information 中会显示 32 位字母数字的 Client ID。不使用 Client secret。
  4. 若其他人也要使用，请在 User Management 中添加其姓名和 Spotify 邮箱。

2. 填入 Kona

  1. 打开设置的“其他”→“Google Drive 和 Spotify”。
  2. 粘贴 Client ID，点击“保存并登录”。
  3. 在 Spotify 的页面上允许访问。
  4. 已保存的专辑会排列在书架上。

此后可从开始画面和“文件夹”菜单打开。若上次打开的是 Spotify，再次打开时会直接进入。

无法正常使用时

提示检查事项
无法登录 SpotifyClient ID 是否正确；Redirect URI 是否与 Kona 显示的完全一致。
播放 Spotify 曲目需要 Premium 账户账号是否为 Premium。
此浏览器无法播放 Spotify 曲目是否为电脑上的 Chrome、Edge 或 Firefox；DRM 受保护内容的播放是否被关闭。
无法在 Spotify 上开始播放是否正在其他设备上操作 Spotify。请稍候再试。

停止使用

  • 在设置的“其他”→“Google Drive 和 Spotify”中点击“退出登录”可删除此浏览器中的令牌；点击“删除 Client ID”可连同设置一并删除。
  • 要撤销权限本身，请在 Spotify 账号的“应用”中移除 Kona。
  • 在控制台删除应用后，Client ID 也随之失效。
