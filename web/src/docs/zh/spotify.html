用 Spotify 收听

Kona 没有服务器。Spotify 的音乐由用户的浏览器直接与 Spotify 通信并播放。为此，用户需在 Spotify for Developers 中自行创建应用，并将其 Client ID 填入 Kona。只需创建一次，不产生费用。

所需条件：Spotify Premium 账号（Web Playback SDK 的规定以及 2026 年 2 月起开发者应用的规定所要求）；支持 DRM（Widevine）的电脑浏览器，如 Chrome、Edge、Firefox。手机浏览器无法播放。

Kona 的界面提供日语和英语。下文使用英语界面的名称；只以日语显示的项目，在括号中附上日语名称。

工作方式

Client ID来自用户自己的 Spotify for Developers。Kona 中不含任何人的 ID。
登录PKCE（不使用客户端密钥的方式）。任何地方都不需要输入密钥。
权限播放（streaming）、个人资料（user-read-email user-read-private，SDK 所需）、读取已保存的专辑（user-library-read）、查看和控制播放设备（user-read-playback-state user-modify-playback-state）。不请求修改播放列表或资料库的权限。
令牌只保存在此浏览器内（localStorage）。退出登录后删除。
通信对象仅 Spotify（accounts.spotify.com api.spotify.com、播放组件 sdk.scdn.co、封面 i.scdn.co）。不向包括开发者在内的任何其他人发送任何内容。
设备上保留的内容令牌，以及播放次数和播放记录（曲名等，与其他专辑相同）。曲目列表和封面不保存，每次打开时从 Spotify 读取。
外部脚本仅在决定使用 Spotify 后，加载 Spotify 的 Web Playback SDK。

可用与不可用的功能

  • 在 Spotify 中保存的专辑会排列在名为 Spotify 的书架上。
  • 书架、猫和播放记录依据曲目信息（曲名、艺人、时长）照常运作。
  • 不加工封面。书脊图案和唱片标签不使用封面，只使用其平均色。
  • 曲目面板中显示 Open in Spotify（Spotify で開く）。
  • Spotify 的音频受 DRM 保护，无法经过 Kona 的音频处理。均衡器、波形、频谱、电平、音量标准化、交叉淡入淡出、环境音和余响均不生效。睡眠定时器会逐渐降低音量后停止。
  • 根据 Spotify 的规定，开发者应用（Development Mode）最多 5 人使用。

1. 创建应用

  1. 打开 Spotify for Developers 控制台，用 Spotify 账号登录。
  2. 点击 Create app，并填写：
    • App name、App description：任意（例如 Kona）。
    • Redirect URIs：原样输入打开 Kona 的 URL（例如 https://wentolia.github.io/kona-open/），末尾的 / 也须一致。复制设置的 Other → Sources 中显示的字符串最为可靠。
    • Which API/SDKs are you planning to use?：选择 Web API 和 Web Playback SDK。
    • 阅读并同意 Developer Terms of Service 和 Design Guidelines，然后保存。
  3. 所建应用的 Settings → Basic Information 中显示 Client ID（32 位字母数字）。不使用 Client secret。
  4. 如有他人使用，请在 User Management 中添加其姓名和 Spotify 邮箱。

2. 填入 Kona

  1. 打开设置的 Other → Sources (Google Drive, Spotify)。
  2. 粘贴 Client ID，点击 Save and sign in。
  3. 在 Spotify 的页面上授权。
  4. 已保存的专辑会排列到书架上。

此后可从开始画面和 Folders 菜单打开。若上次打开的是 Spotify，再次打开时会直接进入。

无法正常使用时

提示（日语）检查事项
Spotify にサインインできませんでした（登录失败）Client ID 是否正确；Redirect URI 是否与 Kona 显示的完全一致。
Premium のアカウントが要ります（需要 Premium）账号是否为 Premium。
このブラウザでは Spotify の曲を鳴らせません（此浏览器无法播放）是否为电脑上的 Chrome、Edge 或 Firefox；受保护内容的播放（DRM）是否被关闭。
再生を始められませんでした（无法开始播放）是否正在其他设备上操作 Spotify。请稍候再试。

停止使用

  • 在设置的 Other → Sources 中点击 Sign out 可删除此浏览器中的令牌；点击 Remove Client ID 可连同设置一并删除。
  • 要撤销权限本身，请在 Spotify 账号的“应用”中移除 Kona。
  • 在控制台删除应用后，Client ID 也随之失效。
