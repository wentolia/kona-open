隐私与使用条款

Kona 是由个人开发、免费公开的浏览器音乐播放器。本文适用于公开版 wentolia.github.io/kona-open 及其源代码。

不收集的信息

  • Kona 没有服务器，也不做访问统计。开发者不会收到用户的音乐、播放记录、设置、姓名或位置。
  • 设置、播放记录和曲目信息只保存在所用浏览器的 localStorage、IndexedDB 和 Cache Storage 中。可在设置的“其他”→“数据”中导出和清除。

离开设备的信息

场景接收方发送的信息
打开公开版GitHub PagesIP 地址等网页服务器通常记录的信息，按 GitHub 的政策处理。
从 Google Drive 收听Google API使用用户自己创建的客户端 ID 登录，以及读取请求。权限仅限读取。
用 Spotify 收听Spotify使用用户自己创建的 Client ID 登录，以及播放操作。
聆听派对四个公开的 Nostr 中继用房间密钥加密的连接信息和一次性公钥。中继无法读取内容，也不保存。
聆听派对STUN 服务器。默认为 Google 的公开服务器，可更改或清空。IP 地址。
聆听派对主持人设置的 TURN 中转服务器，即 Metered、Cloudflare 或主持人选择的服务器。IP 地址以及加密的音频和数据。中转服务器无法读取内容。
聆听派对对方的设备，仅限主持人与参与者之间。彼此的 IP 地址、名字、猫、聊天、通话语音、正在播放的曲名、书架上专辑的标题和缩小的封面、赠送的物品。仅当主持人选择时，包括主持人所在的都道府县或国家。

位置信息

  • 仅在开启“地方特产”时，每天使用一次浏览器的位置信息。
  • 坐标在设备内转换为都道府县或国家代码后立即丢弃，既不保存也不发送。
  • 浏览器或操作系统在获取位置时可能使用 Google 或 Apple 的定位服务，这属于浏览器和操作系统的处理。

通话

  • 仅当主持人允许通话且用户本人打开麦克风时，才使用麦克风。
  • Kona 不录制通话，也不录制音乐。

使用条款

  • Kona 以 MIT 许可证提供，不作任何担保。对于因使用而产生的损害，开发者不承担责任。
  • 请只播放您拥有或有权使用的音乐。
  • 聆听派对请在熟人之间使用。请勿将邀请链接发布到社交媒体等任何人都能看到的地方。所播放音乐的权利由主持人负责。
  • 未满 13 岁者请在监护人陪同下使用。在派对中，主持人可在“权限”中让对方退出，参与者可随时通过“退出”离开。
  • Google Drive 和 Spotify 的客户端 ID 与账号的管理，以及遵守各公司的条款，由用户自行负责。条款为 Google API Services User Data Policy 和 Spotify Developer Terms。Kona 不是 Google 或 Spotify 的官方应用。
  • 所用软件的许可证见 THIRD_PARTY_NOTICES.txt，可从设置的“其他”→“关于 Kona”打开。
