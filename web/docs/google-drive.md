# Google Drive から聴く（設定の手順）

Kona はサーバーを持ちません。Google Drive の曲は、**あなたのブラウザが Google から直接**読みます。
そのために、Google Cloud で「OAuth クライアントID」をあなた自身で一つ作り、Kona に入れます。作るのは一度だけで、料金はかかりません。

## しくみと、守っていること

| | |
|---|---|
| クライアントID | あなたの Google Cloud のもの。Kona には誰のIDも埋め込まれていません |
| 権限 | 読み取りだけ（`drive.readonly`）。Kona は Drive に書き込めません |
| トークン | このタブの中（sessionStorage）だけに置き、約 1 時間で切れます。リフレッシュトークンは受け取りません |
| 通信先 | Google の API（`www.googleapis.com`）だけ。Kona の作者を含め、ほかの誰にも何も送りません |
| 端末に残るもの | 読んだタグとジャケット、「端末に残す」にしたアルバムの曲。ブラウザのサイトデータを消せば消えます |
| 外部スクリプト | 読みません（Google のライブラリも使わず、CSP で禁止しています） |

> **権限の広さについて**: Google の「ファイル選択画面（Picker）」を使えば、選んだファイルだけに権限を絞れます。ただし Picker は Google のスクリプトを読み込む必要があり、「外部のスクリプトを読まない」方針と両立しないため使っていません。代わりに読み取り専用の権限で、Kona の中でフォルダを選びます。

## 1. プロジェクトを作り、Drive API を有効にする

1. [Google Cloud コンソール](https://console.cloud.google.com/) を開き、上のプロジェクト選択から **新しいプロジェクト** を作ります（名前は何でも。例: `kona`）
2. **API とサービス → ライブラリ** で「Google Drive API」を探し、**有効にする** を押します

## 2. 同意画面（Google Auth Platform）を設定する

1. **API とサービス → OAuth 同意画面**（または **Google Auth Platform**）を開き、**開始** を押します
2. アプリ名（例: `Kona`）とサポートのメール（自分）を入れます
3. 対象は **外部** を選びます
4. 連絡先のメールを入れて作成します
5. **対象（Audience）** で、公開ステータスが **テスト中** のままであることを確かめ、**テストユーザー** に自分の Google アカウントを追加します
   - テスト中のままで使えます。審査に出す必要はありません
   - テストユーザーに入れた人だけがサインインできます（家族と使うなら、その人も追加）
6. **データアクセス** で **スコープを追加** から `.../auth/drive.readonly` を追加します（追加しなくてもサインイン時に求められますが、入れておくと画面がわかりやすくなります）

## 3. クライアントIDを作る

1. **クライアント（認証情報）→ クライアントを作成** を押します
2. 種類は **ウェブ アプリケーション**
3. **承認済みの JavaScript 生成元** に、Kona を開いている URL のオリジンを入れます
   - 例: `https://wentolia.github.io`
4. **承認済みのリダイレクト URI** に、Kona を開いている URL を **そのまま** 入れます
   - 例: `https://wentolia.github.io/kona-open/`
   - 末尾の `/` の有無まで一致させます。Kona の Drive の画面に、入れるべき文字列が表示されるので、それをコピーするのが確実です
5. 作成すると **クライアントID**（`…apps.googleusercontent.com`）が出ます。クライアントシークレットは使いません

## 4. Kona に入れる

1. Kona を開き、**設定 → その他 → 読み込み元** の **クライアントIDを入れる** を押します（一度入れると、開始画面の **Google Drive から** と右上の **フォルダを開く → Google Drive** からも開けます）
2. クライアントIDを貼り付けて **保存してサインイン**
3. Google の画面で自分のアカウントを選びます
   - 「Google はこのアプリを確認していません」と出たら、**続行** を押します（自分で作ったアプリなので、審査を受けていないという表示です）
4. 曲の入ったフォルダまで進み、**「◯◯」を開く** を押します

次からは開始画面に **Drive の「◯◯」を開く** が出ます。トークンは約 1 時間で切れるので、切れたら画面のお知らせから **サインインし直す** を押してください。

## スマホで使うとき

- 曲は再生するときに Drive から取ってきます。**モバイル通信だと通信量を使います**（FLAC は 1 曲 20〜40MB ほど）
- よく聴くアルバムは、曲目を開いて **端末に残す** を押すと、ブラウザの中に保存され、次からは通信しません
- タグとジャケットは一度読めば端末に残るので、2 回目からの読み込みは速くなります
- iPhone の Safari は、しばらく使わないサイトのデータを消すことがあります。ホーム画面に追加すると残りやすくなります

## やめるとき

- Kona のダイアログの **サインアウト** で、このタブのトークンを消せます
- 権限そのものを取り消すには、[Google アカウントのサードパーティ接続](https://myaccount.google.com/connections) から Kona を削除します
- Google Cloud のプロジェクトを削除すれば、クライアントIDも使えなくなります
