# Kona のプライバシーと利用条件

Kona は、個人が趣味で作って無料で公開しているブラウザの音楽プレイヤーです。ここに書いたことは、公開版（`https://wentolia.github.io/kona-open/`）とこのリポジトリのコードに当てはまります。

## 集めないもの

- Kona にはサーバーがなく、アクセス解析もしません。作者は、使う人の曲・聴いた記録・設定・名前・位置を受け取りません。
- 設定、聴いた記録、取り込んだ曲の情報は、使っているブラウザの中（localStorage・IndexedDB）にだけ置きます。設定の「データ」から書き出しと消去ができます。

## 端末の外へ出るもの

| 使うとき | 通信先 | 届くもの |
| --- | --- | --- |
| 公開版を開く | GitHub Pages | IP アドレスなど、ウェブサーバーが普通に記録するもの（GitHub の扱いに従います） |
| Google Drive から聴く | Google の API | 使う人が自分で作った Client ID でのサインインと、読み取りの要求。権限は読み取りだけです |
| Spotify で聴く | Spotify | 使う人が自分で作った Client ID でのサインインと、再生の操作 |
| リスニングパーティー | 公開の Nostr リレー 4 つ | 部屋の鍵で暗号化した接続情報と、使い捨ての公開鍵だけ。リレーは中身を読めず、保存もしません |
| リスニングパーティー | Google の公開 STUN（設定で変更・空にできます） | IP アドレス |
| リスニングパーティー | 相手の端末（ホストと参加者の間だけ） | お互いの IP アドレス、名前、猫、チャット、通話の声、流れている曲の名前、棚のアルバムの題名と小さなジャケット。ホストが選んだときだけ、ホストのいる都道府県・国 |

## 位置情報

- 「ご当地の品」をオンにしたときだけ、1 日 1 回ブラウザの位置情報を使います。
- 座標は端末の中で都道府県・国のコードに置き換えてすぐ捨て、保存も送信もしません。
- ブラウザや OS が位置を求めるときに、Google や Apple の位置サービスを使うことがあります。これは Kona ではなくブラウザ・OS の扱いです。

## 通話

- マイクは、ホストが通話を許し、本人がマイクを入れたときだけ開きます。
- Kona は通話も曲も録音しません。

## 利用条件

- Kona は MIT ライセンスで、**無保証** です（リポジトリの `LICENSE`）。使ったことで生じた損害について、作者は責任を負いません。
- 聴く曲は、使う人が自分で持っているか、正しく使える権利のあるものにしてください。
- リスニングパーティーは、知っている人どうしで使ってください。招待リンクを SNS など誰でも見られる場所に貼らないでください。流す曲の権利に気を配るのは、ホストの役目です。
- 13 歳未満の人は、保護者と一緒に使ってください。パーティーで困ったときは、ホストは「権限」から相手を退出させられ、参加者はいつでも「抜ける」で出られます。
- Google Drive と Spotify の Client ID・アカウントの管理と、それぞれの規約（[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)・[Spotify Developer Terms](https://developer.spotify.com/terms)）を守ることは、使う人それぞれの責任です。Kona は Google や Spotify の公式アプリではありません。
- 使っているソフトウェアのライセンスは、公開版の `THIRD_PARTY_NOTICES.txt`（設定の「Kona について」から開けます）にあります。
