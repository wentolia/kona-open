# Kona ブラウザ版

```
npm install
npm run dev          # 開発サーバー
npm run build        # dist/（CSP と同梱の書体つき。GitHub Pages に出すのはこれ）
npm run build:single # dist-single/index.html（1ファイルにまとめたもの）
```

## いまの仕様

### ホーム
- ホームとライブラリの切り替えはフェード（薄く消えて現れる。動きを減らす設定では切り替えるだけ）。
- 配置は「段」の積み重ね。段は横に「列」を並べ、列の中ではモジュールを縦に積める。段の高さは px、列の幅と縦の配分は比率。
- 境目（段の間・列の間・縦積みの間）をドラッグすると大きさが変わる。列の幅は 1/4・1/3・1/2 などに軽く吸い付く。
- モジュールの名前の札は、モジュールの上の隙間に出る（操作する場所と重ならない）。ふだんは隠し、カーソルを乗せると出る。札のクリックで設定ページの「モジュール」タブにそのモジュールの設定を開く、ドラッグで移動。
  - 別のモジュールの端に落とすとその横・上・下に、真ん中に落とすと入れ替え、段と段の間に落とすと新しい段になる。
- モジュール: 棚、再生中、スペクトラム、イコライザー、波形、時計、アルバムの情報、聴いた記録、出力、レコードプレーヤー、窓辺、聴いた距離。棚の上の小物は、モジュールではなくどの棚にも置ける（下の「棚の上の小物」）。
- 画面には説明文やヒントを出さない（空の棚や未再生のモジュールは空のまま）。
- 開き直したときは、再生中だったアルバム（曲と位置）と「次に再生」を戻す。再生は止まった状態から。
- 起動時に記録がなければ、フォルダを選ぶ画面だけを出す。読み込みが終わるまで進捗を出し、棚は見せない。
- 開始画面とメニューの読み込み元は、ふだんは「この端末のフォルダ」だけ。Google Drive と Spotify は、設定の「読み込み元」で ID を入れたときだけ出る。
- タグとジャケットの読み取り結果は覚えておき、次に開いたときは変わっていないファイル（パス・大きさ・更新日時が同じ）を読み直さない（300 枚で約 3 秒 → 0.4 秒）。
- 開き直したとき、前のフォルダを読む許可が残っていればそのまま読む。許可が切れていても（Chrome の既定）開始画面には戻さず、覚えているタグとジャケットで棚と部屋をすぐに出す。
  - 許可は、最初に再生するとき（または「フォルダ」→「読み直す」を押したとき）にブラウザが尋ねる。許可すると、フォルダを読み直して本物のアルバムに入れ替え、押したアルバムをそのまま鳴らす。
  - その間は曲が鳴らせないので、前に聴いていた曲の続きは出さず、上の帯の曲数も出さない（聴いたことのないアルバムの曲数は覚えていないため）。
  - フォルダの画像をジャケットにしているアルバムは、長い辺 320px の写しを覚えておいて出す。
  - 覚えたものをブラウザが空き容量の都合で消さないよう、`navigator.storage.persist()` を頼んでおく。

### 設定ページとテーマカラー
- 上の「設定」から開く（`#settings`。スマホ版は右上の「…」→「設定」）。部屋全体に効く設定と、モジュールの追加・モジュールごとの設定（窓の外の景色・置く小物・スペクトラムの形など）をまとめる。
- 同じ設定を 2 か所に置かない: 棚の素材は設定の「部屋」だけ、設定の書き出し・読み込みは「その他」→「データ」だけ、雨は「出力」の雨の音だけ。
- 上のタブ: 部屋・モジュール・猫・音・その他（スマホ版はモジュールなし）。それぞれ、よく使うものを上に出し、細かなものは「もっと見る」にたたむ。
- **部屋**
  - 色（テーマカラー）: 灯り（既定）・朝靄・昼の書斎・夕焼け・森・深い夜・月明かり・夜桜、または「自分で選ぶ」（地と灯りの色。地は明るくしすぎないよう抑える）。
    - テーマの色はいつも同じ。時刻での色の移ろいは「部屋の明かり」がひとつで受け持つ。
    - 色は CSS 変数（`--bg` `--panel` `--ink` `--accent` など）で、レコード・窓辺・波形などキャンバスのモジュールにも効く。どれも暗い地に限る（夜の部屋を前提に描いているため）。
  - 棚（素材）・壁・床を見本から選ぶ。
  - もっと見る: 部屋の明かりも時刻で変える、棚板に暮らした跡を残す。
- **モジュール**: ホームに並んでいる順の一覧。押すとその場で設定（名前・中身・景色・形など、ホームから外す）が開き、ホームのそのモジュールにも札が立つ。下の「モジュールを足す」で種類を選んで足す（1 つだけ置けるものは、置いてあれば押せない）。
- **猫**: 猫ごとの名前と品種（品種を替えると毛並みを選び直す。性格・お気に入りはそのまま）、呼ぶ・帰す、猫を出さない。遊ぶ: 猫じゃらし、ランダムで1枚（猫がいればくわえてきてもらう）。
  - もっと見る: 夜中にときどき駆け回る、よく聴くアルバムをくわえてきたら（させない / 次に再生に入れる）。
- **音**
  - 音の色（イコライザーのプリセット）: 用意したもの（フラット・低音を足す・声を前に・明るく・夜の小さな音・古いレコード）と、いまの形に名前をつけて残したもの。押すと当たり、自分のものは × で消せる。
  - 曲のつなぎ: ギャップレス（既定）か、クロスフェード 3・6・10 秒。クロスフェードは同じアルバムの中だけで、アルバムの境目はぴったりつなぐ（「次に再生」の切り替えとおやすみタイマーのため）。
  - もっと見る: 音量の正規化（しない / 曲ごと / アルバムごと）、いまの形を残す。
- **その他**
  - ライブラリ: 読み込んでいるフォルダと種類、読み直す・別のフォルダを開く、並び順（ライブラリの箱の中と、新しく作る棚の既定）、括り方（フォルダ / アーティスト。ライブラリの箱・棚の仕切り・スマホの棚に共通）。
  - 文字と言語: 文字の大きさ（小・標準・大・特大。文字の多い所だけを拡大し、棚と猫はそのまま）、書体（ゴシック / 明朝。Zen Old Mincho を同梱）、言語（日本語 / English。替えると開き直す。英語はまだ日本語のままの所がある）。
  - ライブラリの細かな設定: ジャケットがないときの見せ方（色と題名 / 頭文字 / 色だけ）、ほかのアプリから戻ったときの自動の読み直し、動き（端末の設定に従う / 減らす）、端末に残したアルバムの一覧（大きさ・消す）とブラウザの使用容量、フォルダを解除する（確認つき）。
  - データ: 設定の書き出し・読み込み、聴いた記録を消す・すべて初期化する（どちらも確認つき。音楽のファイルは消さない）。
  - キーボード: 割り当ての一覧（変えられない）。Space 再生・一時停止、Shift+←/→ 前後の曲、←/→ 10 秒、↑/↓ 音量、M 消音、1/2/3 ホーム・ライブラリ・設定、/ 検索、Shift+M 最小表示。
  - 読み込み元（Google Drive・Spotify）: Drive のクライアントIDを入れる・フォルダを選ぶ・サインアウト・クライアントIDを消す。Spotify の Client ID・Redirect URI のコピー・サインイン / サインアウト・保存したアルバムを開く・Client ID を消す。
  - Kona について: 版・ライセンス・ソース・プライバシー。

### 写真
- 上の帯の左（KONA の横）の小さなカメラのボタン（ホームのときだけ・PC 版のみ。写真には写らない）で、いま見えている部屋をそのまま 1 枚の写真にする。シャッターの瞬間に猫はその場で止まり、写真の画面を閉じるまでじっとしている。
- 構図は「部屋」（見えている部屋全体）と「猫」（猫に寄った正方形）。猫が何匹かいるときは「猫」を押すたびに次の猫へ。
- 「ジャケットを隠す」（既定でオン・覚えておく）: 写真の中のジャケットを平均色の無地に、背表紙のジャケットの模様を外し、レコードのレーベルも無地にする。画面の表示は変えない。
- メニューやお知らせは写さない。
- 保存（PNG。大きすぎるときは JPEG）、コピー（クリップボードに画像）、共有（端末の共有シート。Web Share API でファイルを渡せるブラウザだけボタンが出る）。写真は端末の中だけで作り、Kona からはどこにも送らない。
- 画像にする機能の入口はこのカメラひとつ。写真の画面の上の札で「部屋」「猫」「レシート」（再生中のときだけ）「証書」（届いた証書があるときだけ）を切り替える。どれも同じ画面（`showPicture`）で保存・コピー・共有する。

### レシート
- 上の帯のカメラ → 写真の画面の札「レシート」（スマホは写真がないので、再生中画面の右上のレシートのボタン）で、いま聴いている曲を感熱紙のレシート風の 1 枚にする。
- 刷るもの: 日時、通し番号（このアルバムの再生回数）と担当（1 匹目の猫の名前）、NOW PLAYING（曲名・アルバム・アーティスト・年・いまの位置）、曲目（いまの曲は反転。18 曲を超えるときはいまの曲の前後だけ）、曲数・収録時間・再生回数・形式・聴いた距離、アルバムごとに決まったバーコード。金額の欄は持たない。
- ジャケットは既定で白黒の点（誤差拡散）で刷る。レシートの画面の「ジャケットを隠す」で刷らないようにでき、写真とは別に覚える（`kona.receiptHideArt`）。Spotify のアルバムは、画像を加工しない決まりのためいつも刷らない。上下はちぎった跡、印字はヘッドの筋でわずかにかすれる。
- 端末の中のキャンバスで描くだけで、どこにも送らない。

### 到達の証書
- 聴いた距離が目じるし（100m 走・東京タワー・富士山・フルマラソン・地球 1 周など）に届くと、その日付とそのとき聴いていたアルバムを覚え、お知らせを出す。記録は端末の中（`kona.awards`）だけ。
- 証書の画像: 金の縁取りの生成りの紙に「到達証」、目じるし、たどった距離と聴いた時間、日付、立会人（1 匹目の猫の名前と肉球）、朱の印。いくつかあるときは画面の上で選べる。
- 開く場所: カメラ → 写真の画面の札「証書」。棚の上の小物の「賞状」（最初の証書が届いてから立つ。届いたばかりのときは額のガラスに光が流れる）と、聴いた距離のモジュールの通り過ぎた目じるしからも開ける。
- この機能より前に通り過ぎた目じるしは、日付の分からない証書（「以前に到達」）として静かに並べる。
- 「聴いた記録を消す」で一緒に消え、「設定と聴いた記録を書き出す」のときだけ書き出す。

### 棚板の跡
- ホームの棚板に、暮らした跡が少しずつ残る（写真にもそのまま写る）。
  - 猫がよく眠る所: その猫の毛色の毛が縁に引っかかり、板の前がうっすら擦れて明るくなる（眠った時間で増える）。
  - 猫がよく跳び乗る所: 細い爪あと（跳び乗った回数で増える）。
- 位置は棚ごとに幅を 48 に分けた区画で覚える（`kona.marks`。端末の中だけ）。棚の幅が変わっても同じ所に残る。
- 設定の「部屋のしつらえ」→「棚板に暮らした跡を残す」で止められる（止めると跡も見せない）。

### スマホ版
- タッチ操作の端末で幅 900px 以下のときだけ、ホーム（モジュールのグリッド）の代わりにスマホ用の画面を出す。PC で窓を狭くしても切り替わらない。`?mobile=1` / `?mobile=0` で固定、`?mobile=auto` で戻す（端末に覚える）。
- 棚の一覧: 上から「次に再生」「最近聴いた」「よく聴く」、続いて選んだフォルダ直下のフォルダごとの棚。各段は指で横に送る。
  - 背表紙をタップすると、その段のジャケットの欄がそのアルバムに替わる。ジャケットをタップするとアルバムのシートが開く（「次に再生」の段はジャケットの欄がないので、背表紙のタップでシート）。
  - 背表紙・ジャケットを長押しすると「次に再生」に入れる（入っていれば外す）。
- 上の検索で、アルバム名・アーティスト・フォルダ・ジャンル・年・曲名から探す。曲名で当たったものは曲の一覧にも出す。
- アルバムのシート: 再生（再生中なら一時停止）、次に再生、Drive のアルバムなら端末に残す、曲目。下になぞるか、外側のタップ、戻るボタンで閉じる。
- 画面の下にミニプレイヤー。タップか上になぞると全画面の「再生中」（ジャケット、シーク、前後、曲目、次に再生）。
- 右上の「…」から、この端末のフォルダ / Google Drive（設定で ID を入れたときだけ）を開き直す、PC 向けの画面に切り替える。
- スマホ版では猫と環境のモジュールは出さない。

### 読み込み元（この端末のフォルダ / Google Drive）
- 開始画面と右上の「フォルダ」から、この端末のフォルダを選ぶ。
- 右上の「フォルダ」のメニュー: 読んでいるフォルダの一覧（× で外す。ファイルや聴いた記録は消さない）、フォルダを追加、読み直す、別のフォルダに入れ替える、Google Drive・Spotify（設定で ID を入れたときだけ）。
  - フォルダはいくつでも足せる（Chrome / Edge）。最初のフォルダの中はそのままのパス、足したフォルダは「フォルダ名/…」として並べるので、最初のフォルダのアルバムの覚え（再生回数・タグなど）は足しても外しても変わらない。同じフォルダは二度入らない。
  - 覚えているフォルダは `kona` の IndexedDB の `roots`（以前の版の `root` 1 つは、読み込むときに移す）。開き直したときは、どのフォルダも許可が残っていればそのまま読む。Google Drive は、設定の「その他」→「読み込み元」でクライアントIDを入れると、開始画面とメニューにも出る。
- Google Drive は、使う人が自分の Google Cloud で作った OAuth クライアントIDを入れて使う（手順: `docs/google-drive.md`）。Kona にはIDを埋め込まない。
  - 権限は読み取りだけ（`drive.readonly`）。トークンはこのタブの中（sessionStorage）だけに置き、約 1 時間で切れる。リフレッシュトークンは持たない。
  - サインインは小窓で開き、開けなければページごと Google へ移って戻る。切れたら「サインインし直す」のお知らせを出す。
  - フォルダは Kona の中で選ぶ（パンくずで戻れる）。選んだフォルダは覚え、次から開始画面に「Drive の「◯◯」を開く」を出す。
- Drive の曲は、タグを読むのに先頭だけを取る（384KB → 3MB → 全体と、足りなければ広げる）。読んだタグとジャケットは端末に覚え、次からは通信しない。
- 再生は曲を取ってから。次の曲は先に取っておく。直近の 3 曲はメモリに置き、波形と再生で二度取らない。
- 曲目パネルの「端末に残す」で、そのアルバムの曲をブラウザの中に保存する（電波のないところでも聴ける・通信量を使わない）。「端末から消す」で消す。
- 再生できるようにする仕組み（EQ・波形・正規化・ノイズなど）は、手元のファイルと同じ。

### Spotify（任意）
- 設定の「その他」→「読み込み元」で、使う人が自分の Spotify for Developers で作った Client ID を入れて使う（手順: `docs/spotify.md`）。Kona にはIDを埋め込まない。サインインは PKCE（シークレットなし）、トークンはこのブラウザの中だけ。
- 棚には保存したアルバムを「Spotify」の棚として並べる。開くたびに Spotify から読み、曲名の一覧やジャケットは端末に覚えない。開始画面と「フォルダ」のメニューに「Spotify」が出る。前に開いていたのが Spotify なら、開き直したときもそのまま。
- 再生は Web Playback SDK（Premium が必要・パソコンのブラウザ）。アルバムの曲を鳴らす順に並べて渡し、曲の境目は Spotify がつなぐ。並べた曲を鳴らし終えたら、Kona の再生のしかた（くり返し・次に再生）で次を決める。
- 音は DRM で守られ Kona の音の経路を通らないので、EQ・波形・スペクトラム・レベル・正規化・クロスフェード・環境音・余韻は効かない（EQ と波形には「Spotify の曲では使えません」と出す）。おやすみタイマーのフェードは、再生先の音量を下げて止める。
- Spotify の表示の決まりに合わせて: ジャケットは切り取らない（背表紙の模様・レコードのレーベルには使わず平均色だけ）、曲目パネルに「Spotify で開く」、写真ではジャケットをいつも隠す。
- 聴いた記録・再生回数・猫・棚は、曲の情報からいつもどおり動く。

### 守っていること（公開しても何も預からない）
- サーバーなし、アクセス解析なし。通信先は Google の API・Spotify（使うときだけ）・リスニングパーティーの Nostr リレー（使うときだけ）だけ。
- 聴いた場所は記録しない。位置情報は使わない（以前の「聴いた場所」モジュールと場所の記録は取り除き、端末に残っていた場所も起動時に消す）。
- 外部のスクリプトを読まない（例外は、Spotify を使うと決めたときの Spotify の Web Playback SDK だけ）。公開用のビルドは CSP（`script-src 'self' https://sdk.scdn.co`・`connect-src 'self' https://www.googleapis.com https://api.spotify.com …` など）で縛り、書体も同梱する。
- タグやファイル名は、必ず文字として表示する（HTML として読ませない）。
- リスニングパーティーも、つなぐための仲介サーバーを持たない（接続情報は公開の Nostr リレーで、暗号化して受け渡す）。

### リスニングパーティー
- ホストが鳴らしている音（EQ のあと・音量の手前）を、そのまま参加者に届けて一緒に聴く。参加者は曲を持っていなくてよい。入口はヘッダーの「招待」（「フォルダ」の左。スマホは右上の「…」）。
  - 音は WebRTC の音声（Opus・ステレオ・128 kbps・DTX なし）。ホストから各参加者へ直接送る（ホストが中心の星形、8 人まで）。少し遅れて届く。
  - 環境音・時計の鐘・猫の音は入れない。Spotify の曲は DRM のため送れない（参加者には「届けられません」と出る）。
- つなぎ方: ホストが「パーティーを開く」→ 招待リンクを送る → 参加者がリンクを開いて名乗り「入れてもらう」→ ホストの画面に「○○さんが入りたがっています」が出る → ホストが「入れる」を押した人だけがつながる。
  - 接続情報（SDP）は、公開の Nostr リレー（`party-relay.ts` の 4 つ）を郵便受けにして受け渡す。Kona はサーバーを持たず、アカウントも鍵の登録もいらない。
  - 「リンクを作り直す」で前のリンクは使えなくなる（いまいる人はそのまま）。
- 参加者はホストの部屋に入る: 部屋の画面は背景や Esc では閉じない（× か「抜ける」で出る）。自分のライブラリ・再生とは切り離し、入っている間は自分のプレイヤーを鳴らさない。音量はパーティー用に別に持つ。出力先だけはこの端末の設定にそろえる。
- 部屋（`party-room.ts`）: 入る先はホストのホームの写し（専用の部屋はない）。入った人はそれぞれ猫になる。ホストは「みんなのいるホームを開く」で同じ画面を見られる（「いつもの画面に戻る」で戻ってもパーティーは続く）。
  - ホームの写し（`party-home.ts`）: ホストのホームの段・列・モジュールの並びと、棚のアルバム（題名・アーティスト・年・色）を送る。見るだけで、ホストの画面は動かない（参加者が棚を送ったりジャケットを替えたりしても、その人の画面の中だけ）。棚以外のモジュールは「いま流れているもの」の札で代える。
  - 見せるアルバム: タグがあれば、ホストは開くときに「すべて / ○○ / ○○ 以外」を選べる（既定は上の帯で選んでいるセット。開いたあとも変えられ、変えるとホームの写しを送り直す）。セットの外のアルバムは、棚・ジャケット・曲目・検索・リクエスト・「かける」のどれにも出さない（流している曲の名前と音は届く）。
  - ジャケットは見えたものから頼み、ホストが約 160px の JPEG に縮めて送る（Spotify など外のジャケットは送らない）。アルバムは不透明な id（`a1` など）で呼び、フォルダの場所は送らない。
  - 猫は入る前に決める: 「ランダムに作る」・品種・「毛色を変える」・性格（元気さ・眠たがり・人なつこさ・遊び好き・好奇心・足の速さ・体の大きさ。動き方のくせになる）。名札は名乗った名前。端末に覚える（`kona.party.cat`）。
  - 棚やモジュールを押すと、自分の猫がいちばん近い足場へ歩く（遠ければ小走り、跳び移れる足場をたどって跳ぶ）。入ったときはいちばん上の棚にいる。位置は「何番目の足場の、幅の何割」でやり取りするので、画面の大きさが違っても同じ所にいる。
  - しぐさ: 立つ・座る・伏せる・寝る・しっぽを振る・リズムをとる（届いた音から拍を拾う。拾えなければゆったり一定に）・毛づくろい・伸び・あくび。
  - 目線: それぞれの猫は、その飼い主のカーソルを見る（0.1 秒おきに知らせる）。
  - 猫は音を出さない。部屋の猫は撫でたり抱いたりできない（自分の猫も、ほかの人の猫も）。
- 権限（ホストの「権限」）: チャット・リクエストの 2 つ。「全員の既定」と、人ごとの「既定 / 可 / 不可」で切り替える。既定はどちらも不可。確かめるのはホスト（参加者の画面のボタンを隠すだけでなく、届いたものをホストが捨てる）。
- アルバムの札: 棚のジャケットや背表紙を押すと、ジャケット・題名・曲目が出る。
- リクエスト（権限があるとき）: 札の「このアルバムをリクエスト」/ 曲ごとの「リクエスト」、またはチャット窓の「リクエストする曲を探す」（題名・アーティストで探す。上位 20 件）から送る。チャットに「○○ のリクエスト」として全員に出て、猫の吹き出しに「♪ 曲名」が出る。ホストには知らせが出て、チャットの「かける」で流せる（流すかはホストが決める）。
- チャット（権限があるとき）: 宛先は「全員へ」か「○○さんだけへ」。
  - 発言は猫の吹き出しと、チャット窓に出る。個別のものは点線の縁で、宛先と送り主の画面にだけ出る（ホストの画面にも、宛先か送り主のときだけ）。
  - 星形なので、個別のものもホストの端末を通って届く（画面にも書いてある）。1 回 200 文字まで。
- 参加者ができること: 聴く・流れている曲名を見る・ホームの写しを見る（棚を送る・ジャケット・曲目）・音量・猫で動く・しぐさ・チャット / リクエスト（権限があるとき）・抜ける。再生の操作はホストだけ。参加者は受け取るだけで、マイクは使わない。
- 守り:
  - 部屋の鍵（ランダムな 32 バイト）は招待リンクの `#party=` 以降にだけ入る。`#` 以降はどのサーバーにも送られず、開いたらすぐアドレス欄から消す。
  - リレーに出すのは、鍵から HKDF で導いた札・AES-GCM の暗号文・使い捨ての公開鍵だけ。リレーは中身（IP アドレスを含む接続情報・名前）を読めない。
  - 出来事はエフェメラル（kind 29391）で、リレーは保存しない。名乗りの公開鍵はページを開いている間だけの使い捨て。
  - リレーを信用しない: 署名を自分で確かめ、差出人の公開鍵を暗号の追加認証データに入れる（他人の名乗りに付け替えられない）。2 分より古い知らせは捨てる。
  - 招待リンクにはホストの公開鍵も入れ、参加者はホストからの知らせしか読まない（リンクを知る別の人がホストをかたれない）。
  - ホストが「入れる」を押さない限りつながらない。入りたい人の列は 8 人まで。
  - 参加者どうしはつながらない（参加者どうしで IP アドレスは見えない）。ホストと参加者の間では見える（画面にも書いてある）。
  - 相手から届いたものは形と大きさを確かめてから使い、画面には esc() / textContent でだけ入れる。
  - 届いた猫は、色が色の形をしているか（SVG にそのまま書くので）を確かめ、知っている項目だけを写す（品種は知っているものだけ、性格は範囲に収める）。
  - 部屋のやり取りは、ホストが送り主の猫の id を付け直して中継する（ほかの人の猫をかたれない）。送りすぎはホストで捨てる（目線は 1 秒 20 回ほど、チャットは 1 秒 2 回ほど）。権限を変えられるのはホストだけ。ホームの写しを頼むのは 1 回で重め（目線 30 回ぶん）に数える。
  - 公開版の CSP は、接続先をこの 4 つのリレーだけに足している。
- つなぎ方の設定: 既定は Google の公開 STUN（相手までの道を調べるため、IP アドレスが Google に届く）。空にすると同じ LAN の中だけでつなぐ。つながらない回線どうしでは、自分で用意した TURN を `turn:host:3478?username=…&credential=…` の形で書ける。
- 開発で手元のリレーを使うときは、localStorage の `kona.party.relays` にリレーの URL の配列を入れる（公開版は CSP で 4 つ以外につながらない）。

### 棚
- 棚の中身は 3 種類だけ。
  - **アルバム（検索と並び順）**: 検索語と並び順で中身が決まる。検索語が空ならすべて。並び順はアルバム名・アーティスト・年（新しい順 / 古い順）・再生回数（面陳は上位 2 枚と回数）・最近聴いた順・ジャケットの色の順。以前の「よく聴く」「最近」「フォルダ」「アーティスト」「気分」の棚は、どれもこの棚の検索語と並び順の組み合わせで作る（古い配置は開いたときに自動で置き換える）。
  - **次に再生**（下の「再生と『次に再生』」）。
  - **小物だけ**: アルバムを並べず、置いた小物だけを棚いっぱいに並べる（以前の「雑貨」の棚）。
  - 検索語が `tag:名前` だけの棚には、アルバムをドラッグして落とせる（落とすとそのタグがつき、外へ出すと外れる）。以前の「手動の棚」はこれで置き換え、入っていたアルバムには棚の名前のタグをつける。
  - 棚の中の検索窓は、検索語を自分で打つ棚だけに出す（再生回数・最近聴いた順・色の順の棚、タグの棚、項目指定の棚には出さない）。
- 棚の素材は、猫や上の帯と同じく多角形で刻んだパイン（既定）・白樺・黒檀・石・苔・雪（節・釘・三角の棚受けつき。`src/shelf-lowpoly.css` は `scripts/shelf-lowpoly.py` で作る）から選ぶ。設定の「部屋」→「棚」で選ぶ（スマホも設定から）。すべての棚（ホーム・ライブラリ・小物や猫の家具の板）と、レコードプレーヤーの台・窓辺の枠に効く。端末に覚える。
- 上の帯（ヘッダー）も同じローポリの言葉で作る: 帯は大きな三角形の面を数段の濃淡で塗り分け、下の端は低い稜線（形は `scripts/header-lowpoly.py` で作る `src/header-lowpoly.css`、見た目は `src/header.css`）。タブは六角の札、窓のボタンは触れると三面の六角、「招待」「フォルダ」は角を落とした板。色はテーマ色から計算するので、テーマ・部屋の明かりと一緒に移る。スマホ版の上（ロゴ・検索）も同じ帯で、検索欄は六角の札。写真のカメラは左の KONA の横に小さく薄く置き、触れたときだけはっきり見せる。モジュールの追加は設定ページの「モジュール」タブで。
- ジャケット欄は棚の中の決まった位置（左端・途中・右端）に固定し、ドラッグで動かせる。
- 欄が途中にあるときは、欄の左右の窓に 1 本の列を続けて見せる（欄は区切りで、裏に本を隠さない）。
- 窓の端で一部しか見えない背表紙は出さない。ホイールで送ると、背表紙の左端がそろう位置で止まる。
- 送れる範囲は、列の頭が左の窓の左端に来るところから、最後の1冊が右の窓に収まるところまで（窓が空にならない）。
- ジャケットは正方形でなくても切らずに、正方形の欄の中に収める。
- 「フォルダごとに隙間をあけて仕切る」をオンにすると、フォルダごとにまとめ、継ぎ目に隙間をあける。

### 再生と「次に再生」
- 再生のしかた: 再生バーの右のボタンを押すたびに 通常 → アルバムリピート → 1 曲リピート → アルバム内シャッフル と巡る（スマホは再生中画面の右上）。覚えておく。
  - 1 曲リピート中も「次の曲」ボタンでは次へ進む。シャッフルはアルバムの中だけで、アルバムを聴き終えると「次に再生」へ移る（次のアルバムもシャッフル）。
  - アルバムリピート中でも、スリープタイマー「アルバムの終わり」では止まる。
- 曲間を空けない: 再生中に次の曲（アルバムの最後なら、次に切り替わるアルバムの 1 曲目）を 2 つ目の再生器に読み込んでおき、曲が終わる瞬間に切り替える。「次に再生」が変われば先読みし直す。
  - ブラウザが再生できない曲（対応していない形式・壊れたファイル）は飛ばして次へ進み、下に短く知らせる。
  - ブラウザの制約で完全なギャップレスではない（切り替えに 10 ms ほどかかり、MP3 などのエンコーダの無音は残る）。
- 曲やアルバムが替わるときは、表示をパッと変えない。再生中のジャケットと情報カードは薄く消えてから現れ、曲名はフェードで入れ替わる。波形は今の形から次の曲の形へ柱がゆっくり移り、レコードのレーベルは前のジャケットから溶けるように替わる。
- 背表紙のクリックで曲目パネル、ダブルクリックでその場で再生。
- 「次に再生」にはドラッグで入れたアルバムだけが並ぶ。今のアルバムを最後まで聴くと、自動でここのアルバムに切り替わる。
  - 切り替わる先: 「次に再生」の中から選んで聴いていればその右隣、そうでなければ先頭。
  - 最後まで聴いたアルバムは「次に再生」から外れる。
- どの棚から選んでも、再生中が切り替わるだけで「次に再生」の中身は変わらない。
- 「次に再生」の外へドラッグして落とすと、棚に戻す（「次に再生」から外れる）。タグの棚に落とせば、そのタグをつけたうえで外れる。
- 「次に再生」の面陳は、背表紙にカーソルを乗せると替わり、カーソルが離れると次に切り替わるアルバムに戻る。

### 最小表示と小窓
- 右上のボタンで最小表示に切り替える: ジャケット・曲名・シーク・前／再生／次だけ。右端のボタンで元の表示に戻す。開き直しても覚えている。
- ウィンドウの高さを 220px 以下にすると、自動で最小表示になる。
- 最小表示は窓の大きさに合わせて形を変える: 横長なら 1 列、細いと再生ボタンだけ、縦に余裕があればジャケットを大きく縦に積む。
- アプリとしてインストールしたウィンドウでは、最小表示にするとウィンドウごと小さく（420×132）なり、戻すと元の大きさに戻る。
- 小窓: 常にほかのウィンドウより手前に出るミニプレイヤー（Document Picture-in-Picture。Chrome / Edge 116 以降のみ。非対応のブラウザではボタンを出さない）。再生中にタブを離れたとき自動で小窓を出すこともできる（ブラウザ側で許可したとき）。

### タスクバーと OS のメディア操作
- アプリとしてインストールできる（Chrome / Edge のアドレスバーの「インストール」）。タスクバーやスタート、Dock に独立したアプリとして置ける。
- ウィンドウ名（タスクバーやタブに出る）は「曲名 — アーティスト · Kona」。
- OS のメディア操作（メディアキー、Windows のメディアパネル、macOS のコントロールセンター、スマホのロック画面）に曲名・ジャケット・進み具合を出し、再生／一時停止・前後の曲・シーク・10 秒送り／戻しができる。
- 一度開いた画面のファイルは手元に残し、ネットワークがなくても開ける（音楽は元々手元のフォルダから読む）。
- ブラウザの制約で、タスクバーのサムネイルに独自のボタンを足すことや、タスクバーに常駐する細いバーは作れない。

### ライブラリ
- 複数選択: 背表紙やジャケットを Ctrl（Mac は ⌘）クリックで 1 枚ずつ、Shift クリックで前に選んだところからまとめて選べる（ホームの棚でも同じ）。選んでいる間は下に帯が出て、まとめて「次に再生」に入れる・外す、ライブラリから外す ができる。選んだうちの 1 枚をドラッグすると、まとめて棚や「次に再生」へ運べる。Esc で選ぶのをやめる。
- 設定の書き出し・読み込み: 設定の「その他」→「データ」から。配置・イコライザー・再生のしかたなどを JSON ファイルにして、別の端末で読み込める（サーバーは使わない）。聴いた記録（再生回数・日時）は「設定と聴いた記録を書き出す」のときだけ入れる。Drive のサインイン情報と、この端末だけの状態は入れない。
- ライブラリから外す: 背表紙の曲目パネルの「ライブラリから外す」でアルバムを、フォルダの札に乗せると出る × でフォルダごと外せる。ファイルは消さず、アプリの棚・検索・次に再生に出さないだけ。外した直後は「元に戻す」が出る。
- 外したアルバムはライブラリの一番下「外したアルバム」にたたんでおき、1 枚ずつ、またはすべて戻せる。開き直しても覚えている。
- 「読み直す」（上の帯の「フォルダ」のメニュー。フォルダを選んで開いたときだけ出る）: 足したフォルダも含めて フォルダをもう一度たどり、増えた・減った・中のファイルが替わったアルバムだけを反映する。棚と再生はそのまま。結果は下に短く出る。
  - ほかのアプリから Kona の画面に戻ってきたときも、ひとりでに読み直す（1 分に 1 回まで。変わりがなければ何も出さない）。
  - フォルダの見張り: 手元のフォルダは、変更を知らせてくれるブラウザ（Chrome / Edge の FileSystemObserver）なら、曲を足す・消すと数秒で反映する。ないブラウザでは、画面を見ている間 3 分ごとに読み直す。Google Drive のフォルダは、画面を見ている間 10 分ごとに読み直す（メニューに「読み直す」も出る）。
- フォルダを画面にドラッグ&ドロップしても開ける。Chrome / Edge では次回もそのまま開け、「読み直す」も使える。
- フォルダごとに箱にまとめ、箱を左から詰めて棚の段に割り付ける。枚数が多くても少なくても同じ密度で並ぶ。
- 下の再生バーには、ジャケット・曲の操作・曲目を出す。
- 段に収まった箱は、もとの幅に比例して右端まで広がる（段の右に空きを残さない。背表紙は箱の中で左に寄せる）。
- 右上の検索窓はスクロールしても上に残る。検索窓で絞り込める（ホームの検索の棚と同じ書き方。artist: genre: year: folder: tag: mood: と、空白を含む語は "…" で囲む、頭の - で除くことも使える）。当てはまらないフォルダは箱ごと隠れる。

### タグとアルバムのセット
- フォルダ単位・アルバム単位で、自分でタグをつけられる。アルバムのタグは、そのアルバムのフォルダと上のフォルダのタグを合わせたもの（フォルダにつけると中のアルバムすべてに効く）。
  - つける場所: ライブラリのフォルダの札（乗せると「タグ」が出る。アーティストで括っているときは中のアルバムそれぞれに）、曲目パネル、複数選択の帯。
  - 小さなパネルで、今あるタグを押してつける / 外す、新しいタグは入力して Enter。どこにもつかなくなったタグは消える。上のフォルダから受け継いだタグは点線で見せるだけ。
- 上の帯のタブ（タグがあるときだけ出る）で、ホーム・ライブラリ・スマホの棚に出すアルバムのセットを切り替える。既定は「すべて」。
  - タグを押すとそのタグのアルバムだけ。もう一度押すと「そのタグ以外」（灯りの色）、さらに押すと「すべて」に戻る。
  - 「次に再生」はそのまま残し、セットの外のアルバムは飛ばす。開き直すと「すべて」に戻る。
- 検索で `tag:`（`t:`）が使える。頭に `-` をつけるとどの語も「含まない」になる（例: `-tag:ひみつ`）。タグの名前は普通の語でも当たる。
- プレイリストではない: 曲の並びは持たず、アルバムの見せ方を切り替えるだけ。

### イコライザー
- 7 バンド（60 / 150 / 400 / 1k / 2.4k / 6k / 12k Hz）。フェーダーは溝のどこを押してもそこへ動き、ダブルクリックで 0 dB、矢印キーで 0.5 dB ずつ。
- 持ち上げた最大量だけ自動でプリアンプを下げ、音割れを防ぐ。オン・オフと「フラット」。設定は保存される。
- フェーダーの奥に、合成した応答カーブを描く（各フェーダーの真上がそのバンドの周波数）。

### 波形
- 再生中の曲全体の波形を細い柱で描き、聴いた分は灯る。一度描いた曲の形は端末に残し、次からはデコードせずにすぐ出す。カーソルの位置の時刻を出し、クリックでそこへ移る。

### 時計とおやすみタイマー
- 時刻と日付。その下の無地のボタンを押したときだけ、タイマーの選択肢を出す（選ぶと閉じる）。動いている間はボタンが灯り、残り時間だけを出す。
- おやすみは 15 / 30 / 60 分か「アルバムの終わり」。時間が来たら 8 秒かけて音を絞って止める。

### アルバムの情報
- 再生中のアルバムを図書館の貸出カードのように見せる（書誌・曲数と長さ・形式・再生回数、聴いた日のスタンプ）。

### 聴いた記録
- 週ごとに 1 段（8 週分）。その週に聴いたアルバムを小さな背表紙で並べ、よく聴いたものほど太く高い。ダブルクリックで再生。

### 出力
- 出力先の機器（対応ブラウザのみ）、いまの信号の流れ（音量の正規化は設定の「音」で変える）。
- 重ねる音: ホワイト・ピンク・ブラウンのノイズ、雨・焚き火・波・レコードのチリチリを、それぞれ好きな音量で音楽に重ねられる（いくつでも同時に）。再生中だけ鳴り、音楽と一緒にゆっくり現れて消える。音量とフェード（スリープタイマー）は音楽と共通で、メーターや波形には入らない。つまみのダブルクリックで 0。音はその場で作り、数秒〜24 秒をつなぎ目なく繰り返す。
- ブラウザの制約で、ギャップレス再生や排他モード・ビットパーフェクト出力はできない。

### レコードプレーヤー
- 再生中のアルバムをレコードに見立てる。ジャケットがレーベルで、再生中は 33⅓ 回転で回る（回り始め・止まりぎわはゆっくり）。
- トーンアームはアルバム全体の進み具合で外周から内周へ寄る。盤か、左下のスタートボタンのクリックで再生・一時停止。
- 木の台、金属の縁のターンテーブル（縁のストロボの点が回転と一緒に流れる）、音溝と曲の切れ目の無音帯、回っても動かない光の映り込み。
- アームは軸受け・おもり・ヘッドシェルを持ち、アルバムが入るとアームレストからゆっくり盤へ降りる。回っている間はボタン横の灯りが点く。

### 窓辺
- いまの時刻の空。朝焼け・昼・夕焼け・夜が移り、太陽と月が弧を描いて横切る。
- 窓そのもの: 木の外枠、壁の厚み（奥行き）、今どきの引き違い窓（細いアルミ枠に大きな一枚ガラスが 2 枚、真ん中で前後に重なる。クレセント錠と引き手、下枠のレール）、猫が座れる窓の下の桟。
- ガラスに斜めの映り込み。夜は部屋の灯りがうっすら映る。左端に薄いカーテンがあり、音に合わせてわずかに揺れる。
- 外: 流れる雲（朝夕は下から染まる）、昼にときどき横切る鳥、奥と手前の 2 層の街並み、夜に点滅する鉄塔の赤い灯り、ビルの窓の灯りが少しずつ点いたり消えたりする。

- 窓の外の景色は、窓辺の札から選ぶ。
- 雨: 「出力」で雨の音を重ねているときに降る（雨の設定はこれひとつ）。空は灰色に曇り、外に細い雨の筋、ガラスには雨粒がつく。
  - 曲の拍（音の立ち上がり）の速さで雨粒の数が、音の大きさで粒の大きさが決まる。静かな曲ほど細かい雨になり、拍に合わせて粒が増える。
  - 大きな粒はやがて流れ落ち、途中の小さな粒を拾って太り、跡を残す。止むと粒はゆっくり乾く。
### 聴いた距離
- 聴いた時間の合計を、レコードの溝をたどった長さに換算する（33⅓ 回転・平均半径 11 cm で毎秒約 0.38 m）。
- 次の目じるし（東京タワー・富士山・フルマラソン・地球 1 周など）までの進み具合を、目盛りのある線と光る点で見せる。左に通り過ぎた目じるし、右に次の目じるしと残りの距離。

### 気分（`mood:`）
- ジャケットの平均色から、夜・静か・明るい・温かい・涼しい に振り分ける。検索で `mood:夜` のように絞り、並び順「ジャケットの色の順」と合わせると以前の「気分の棚」になる。

### 棚の上の小物
- 小さな棚板に、ランプ・鉢植え・ろうそく・マグ・メトロノームが立つ。ランプはクリックで点く。鉢植えは揺れ、ろうそくの炎は音の大きさで伸び縮みし、マグは再生中だけ湯気が立ち、メトロノームは音に合わせて振れる。
- 鉢植えは季節の植物: 音楽を聴いた日の数だけ育つ（芽から、30 日ほどで茂る）。春は花が咲き、夏は濃く大きく、秋は外側の葉から色づいて棚に落ち葉が増え、冬は葉を減らしてくすんだ色でじっとしている。
- 小物はどの棚にも置ける。棚の設定（札をクリック → 設定の「モジュール」）の「置く小物」で選ぶと、その棚のアルバムの右に立つ（「小物だけ」の棚では棚いっぱいに並ぶ）。大きさは棚の高さに合わせ、並べる数が多いときは棚の幅の半分に収まるまで縮める。
- 小物はひとつずつしかない（灯りの点き消し・ろうそく・植物の育ちぐあいは部屋にひとつ）ので、置けるのはひとつの棚だけ。ほかの棚に置いてあるものは、選ぶとこちらへ移る（一覧に今の棚の名前が出る）。
- 置き場所は棚の配置（`kona.layout` の `goods`）に覚える。以前の「雑貨の棚に何を置くか」（`kona.objects` の `hide`）は、開いたときに一度だけ最初の雑貨の棚へ移す。

### 猫
- ローポリの猫が、ホームの棚板の上を歩き、別の棚へ跳び移り、座ったり寝そべったり眠ったりする。たいていはじっとしている。
- 背表紙の前でも見分けられるよう、背後に暗い影・輪郭に細い明るい縁を入れ、目はかすかに光る。
- 脚は骨ごとに分かれ、逆運動学で肉球の位置から関節の角度を決める。骨格の比率は本物の猫に合わせている。
  - 前脚: 肩甲骨は背中の上（き甲）から胸の前へ斜めに下り、脚と一緒に前後へ振れる。肩関節は胸の前、上腕は短く、肘は胸の下端。前腕は長くほぼ垂直。
  - 後ろ脚: 股関節は腰の高い位置。膝はお腹の線まで前に出て、かかとは高く、中足は長い（つま先立ちで歩く）。
- 跳び方: 身を沈めて着地点を見つめる溜め（高い所ほど長く、遊び好きな子はお尻を振る）→ 一瞬で全身を伸ばす踏み切り → 重力どおりの放物線（踏み切り直後は後ろ脚が伸び、前脚を前へ、降りぎわに前脚を下へ）→ 前脚から着地して肘と膝で衝撃を吸い込み、ゆっくり戻る。
  - 歩き方は猫の並足（後ろ左→前左→後ろ右→前右）で、肉球は置いたら滑らせず、低く上げてそっと下ろす。歩くときは頭を少し下げ、背中はほとんど揺らさない。
- クリックすると座ってのどを鳴らす。カーソルが近づくとそちらを向く。動きを減らす設定のときは歩かず跳ばない。
- 居場所: 棚板のほか、モジュールの上（再生中・レコードの上は音楽が鳴っていると温かくて好き、時計の上も好き）、窓辺の桟、床。足場ごとに好みの重みがあり、暖かい所や窓辺では眠りやすい。
- お気に入り: 猫ごとに好きなアルバムが 1 枚ある（はじめて呼んだときに決まり、開き直しても同じ）。ときどきその背表紙の前へ行って丸くなって眠る。そのアルバムが流れているときは何度も行きたがり、着くとまず喉を鳴らす。
- 性格: 元気さ・眠たがり・人なつこさ・遊び好き・好奇心・足の速さ・体の大きさを、猫ごとにランダムに持つ。歩く・跳ぶ回数、眠る長さ、ほかの猫に関わる頻度、行き先が変わる。
- 猫どうし: 毛づくろい（お返しに舐め合って、寄り添って眠る）、じゃれ合い（前脚でちょいちょい、小さく跳ねる）、ちょっかい（寝ている子を叩く。相手しだいで追いかけてくる・じゃれ返す・知らん顔）、追いかけっこ（速足で走り、足場を跳び移って逃げる・追う）。
- ごくまれに、よく聴くアルバムの背表紙を棚からくわえて、「次に再生」の棚まで運んで入れてくれる。
- 呼ぶと画面の端から駆け込んでくるか、上から飛び込んでくる。帰すと端まで走り去るか、ひょいと飛び降りていなくなる。
- 追加メニューの「猫を呼ぶ」「猫を帰す」で何匹でも置ける（はじめは 1 匹）。毛並み（黒・灰・ブルーグレー・茶トラ・こげ茶・クリーム・白、ハチワレ、目の色）は呼んだときにランダムに決まり、開き直しても同じ子が居る。
